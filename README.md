# Fair Allocation Blog

A bilingual static research blog about fair allocation, EF1, Nash social welfare, and PriorityNet.

- Traditional Chinese: <https://ygjh.github.io/fair_allocation_blog/>
- English: <https://ygjh.github.io/fair_allocation_blog/en/>

## Edit the article

Update either Markdown source:

- `content/research-paper-blog.zh-TW.md`
- `content/research-paper-blog.en.md`

The GitHub Pages workflow rebuilds and deploys the site after every push to `main`.

## Local preview

```bash
npm ci
npm run dev
```

The static output is generated in `dist/`.
